# 🧋 Boba Bash — Discover Your Boba Personality

**Your vibe. Your flavor. Your story.**

Boba Bash is a fun, interactive personality quiz that matches your vibe with a boba tea personality! Answer playful questions, discover your boba alter ego, and explore the different personalities with your friends.

## ✨ Features

- 🧋 **Interactive Personality Quiz:** Answer 8 fun questions to discover your boba personality.
- 💜 **Five Unique Personalities:** Meet the Strawberry Sweetheart, Taro Enigma, Matcha Main Character, Brown Sugar Boss, and Blueberry Chaos.
- 🎨 **Dark Neon Design:** A dark background with glowing purple and pink accents.
- 📊 **Personality Scoring:** Your answers determine which personality matches you best.
- 🔄 **Retake the Quiz:** Take the quiz again to discover your result.
- ♡ **Boba Compatibility Demo:** Explore a playful compatibility feature.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your browser, or use the VS Code Live Server extension.
5. Click **Discover My Boba** and start the quiz!
